# AI-Assisted Development Disclosure

## Overview

Bisync Hub (Safety-First Dashboard & Automation Engine for Rclone Bisync) is developed using an AI-assisted software engineering workflow.

Artificial intelligence tools are used throughout the lifecycle of the project to accelerate development, improve documentation quality, assist with testing, and explore architectural options.

AI assistance is an enabling technology for this project and has significantly expanded what can be achieved by a single maintainer.

---

## How AI Is Used

AI tools may assist with:

- Feature implementation
- Refactoring
- Test generation
- Documentation authoring
- Architecture reviews
- Code reviews
- Design discussions
- Bug investigations
- Release planning
- Development workflows

AI assistance may be used for both new development and maintenance activities.

---

## Human Oversight

AI-generated output is not automatically accepted.

All changes included in the project are:

- Reviewed by the maintainer
- Evaluated for correctness
- Assessed for security implications
- Tested before release
- Aligned with project architecture and design principles

The maintainer remains responsible for all code, documentation, releases, and project decisions.

---

## Development Philosophy

AI is treated as an engineering assistant rather than an autonomous developer.

The project follows a human-in-the-loop development model in which:

1. Requirements are defined by the maintainer.
2. AI may assist with implementation proposals.
3. Output is reviewed and refined.
4. Final decisions remain with the maintainer.

The project's architecture, roadmap, and long-term direction are determined by humans, not by AI systems.

---

## Limitations

Like any development tool, AI systems can make mistakes.

Potential issues include:

- Incorrect assumptions
- Incomplete implementations
- Faulty code suggestions
- Security oversights
- Outdated recommendations

For this reason, all contributions—whether written by humans or generated with AI assistance—are subject to review and validation.

---

## Contributions

Contributors are welcome to use AI tools when preparing pull requests.

However, contributors remain responsible for:

- Understanding submitted code
- Testing submitted changes
- Maintaining code quality
- Following project architecture principles

Pull requests may be rejected if they introduce:

- Unreviewed generated code
- Excessive complexity
- Security concerns
- Inconsistent architecture

---

## Sustainability

The project relies heavily on commercial AI-assisted engineering tools.

These tools incur recurring costs and directly influence the pace at which new features, bug fixes, documentation, and improvements can be delivered.

Community sponsorship helps offset these costs and supports the continued development and maintenance of the project.

Support is entirely optional, and the project will remain free and open source.

---

## Transparency Commitment

The project maintainer is committed to being transparent about the use of AI-assisted development practices.

Users and contributors should assume that portions of the codebase, documentation, tests, and planning artifacts may have been created with AI assistance and subsequently reviewed, modified, and approved by a human maintainer.

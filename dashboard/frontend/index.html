OAuth App Configuration

Configure personal Google Cloud credentials to avoid service limits

Why personal credentials?

Rclone's shared Google Drive client ID is subject to global API quotas and upcoming retirement. Creating your own free Google Cloud OAuth client guarantees reliable bidirectional syncing without quota throttling.

Setup Instructions:
  1. Open the Google Cloud Console ↗ and create a project.
  2. Enable the Google Drive API under APIs & Services → Library.
  3. Configure the OAuth Consent Screen (User Type: External, Publishing status: Testing, add your email as a test user).
  4. Go to Credentials → Create Credentials → OAuth Client ID.
  5. Select Desktop app as Application Type, then copy the Client ID and Client Secret below.
Your secret is securely written to rclone config and never revealed in telemetry or logs.

If the browser did not open automatically: Open OAuth Authorization Page ↗

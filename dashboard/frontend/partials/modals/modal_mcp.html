Model Context Protocol (MCP)

Agentic synchronization, conflict review inspection, and diagnostics
Transport Protocol
Process ID (PID)
Server SSE Endpoint
Security Mode Configuration

Read-only mode guarantees that AI agents can inspect status, telemetry, logs, and dry-run compilations, but cannot trigger synchronizations or resolve conflicts.

# Toggle read-only mode in ~/.config/rclone-bisync/bisync.env:
MCP_READ_ONLY=true
# Or restart systemd user service:
systemctl --user restart rclone-dashboard.service
Add the snippet below to your client's MCP configuration file (e.g. ~/.config/Claude/claude_desktop_config.json).

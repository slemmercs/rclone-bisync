# Implementation Plan: TypeScript Contract Generator & Showcase Redesign

## Proposed Changes

Implement a native Go AST $\rightarrow$ TypeScript interface generator (`--ts-out`) as **Priority 1** to permanently eliminate contract drift, modularize `cmd/gendocs/`, gate sandbox screenshot capture, and overhaul the GitHub Pages documentation showcase (`site/`) with the **Agnoster Carbon & Electric Blue** design system.

---

### Priority 1: Native Go AST $\rightarrow$ TypeScript Contract Generator (`--ts-out`) & Modularization

1. **Native TypeScript Interface Emitter (`cmd/gendocs/ts_generator.go`)**:
   - Parses Go AST across `internal/models/` and `internal/profiles/model.go`.
   - Maps Go primitive types, slices, maps, and structs:
     - `string` $\rightarrow$ `string`, `int/float` $\rightarrow$ `number`, `bool` $\rightarrow$ `boolean`
     - `[]T` $\rightarrow$ `T[]`, `map[string]T` $\rightarrow$ `Record<string, T>`, `any` $\rightarrow$ `any`
     - Pointer types (`*T`) or `json:"...,omitempty"` $\rightarrow$ optional fields (`field?: type`)
     - Fields tagged `json:"-"` are omitted.
     - Go doc comments translated into typed JSDoc (`/** ... */`) blocks.
     - Emits `dashboard/frontend/src/types/models.gen.ts` (`// Code generated by cmd/gendocs. DO NOT EDIT.`).
   - Re-exports generated interfaces in `dashboard/frontend/src/types/models.ts` while preserving custom UI unions.

2. **Modular Architecture for `cmd/gendocs/` (< 200 LOC per file)**:
   - `main.go`: CLI flags (`--out`, `--ts-out`), file writing orchestration.
   - `ast_parser.go`: `go/ast` struct inspection, tag evaluation, comment extraction.
   - `ts_generator.go`: TypeScript emitter converting AST structs into TS interfaces.
   - `mcp_docs.go`: Model Context Protocol tool definitions and blast-radius table compiler.
   - `render.go`: Markdown output formatting, Jekyll front matter, and markdown tables.

3. **Build Targets in `Makefile`**:
   - `make generate-ts`: Runs `go run ./cmd/gendocs --ts-out dashboard/frontend/src/types/models.gen.ts`.
   - Validates generated TS with `npm --prefix dashboard/frontend run type-check`.

### Priority 2: Gated E2E Screenshots & High-DPI Polish

1. **Gating `TestCaptureSandboxScreenshots`**:
   - Guard `tests/e2e/screenshots_test.go` with `if os.Getenv("CAPTURE_SCREENSHOTS") != "1" { t.Skip(...) }`.
   - Standard `go test ./...` and `./scripts/check.sh all` skip heavy headless Chrome execution.

2. **High-DPI Retina & Zero-Animation Rendering**:
   - Configure `chromedp.EmulateViewport(1440, 900, chromedp.EmulateScale(2))` for razor-sharp typography.
   - Inject CSS snippet (`*, *::before, *::after { transition-duration: 0s !important; animation-duration: 0s !important; }`) to eliminate mid-fade modal artifacts.

3. **Makefile Integration**:
   - Add `frontend-build` target (`npm --prefix dashboard/frontend run build`).
   - Wire `make docs-screenshots` to run `frontend-build` before `CAPTURE_SCREENSHOTS=1 go test`.

The Bidirectional Dilemma

Standard bidirectional synchronization tools face a fundamental challenge: How do you reconcile silent file deletions and conflicting concurrent edits without risking catastrophic data loss?

Raw rclone bisync provides raw power across 40+ storage providers, but in production, silent automated runs can propagate accidental directory purges, overwrite newer files due to cloud timestamp skews, or deadlock when token expirations occur.

Bisync Hub surrounds rclone bisync with an unyielding safety envelope:

● Available Now

Interactive Sync Review

Diff previews and dry-run deletion guards block bulk modifications until explicitly approved by an operator or policy.

● Available Now

Confidence-Scored Conflicts

Multi-analyzer resolution evaluating size divergence, binary signatures, cloud clock skew, and edit velocity.

◆ Planned Roadmap

Configurable Safety Policies

Declarative pre-execution and pre-mutation rules with strict delete percentage bounds and canary file protection.

● Available Now

Cryptographic Audit Ledger

Tamper-evident audit trail with SHA-256 hash chains, trigger-enforced append-only tables, and POSIX advisory locking.

Architectural Pillars & Delivery Status

Explore the deep technical architecture powering Bisync Hub:

  1. Interactive Sync Review & Deletion Diff Visualizer Available: Full visibility into pending cloud mutations before any files are altered or removed.
  2. Multi-Analyzer Heuristic Conflict Engine Available: Multi-signal confidence calculation eliminating blind last-modified-wins data loss.
  3. Customizable Safety Policies & Circuit Breakers Planned: Pre-execution canaries, max-delete ratios, and rate-limit backoff handling.
  4. Cryptographic Immutable Audit Ledger Available: SQLite triggers and SHA-256 hash chains providing tamper-proof sync accountability.
  5. Zero-Dependency Single Binary Distribution Available: Native Go executable with embedded Web UI, zero Python/pip/npm runtime requirements.
